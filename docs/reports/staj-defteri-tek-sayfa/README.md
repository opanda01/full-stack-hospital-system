## Word'e aktarma

Her `gun-XX.md` dosyası tek A4 sayfasına sığacak şekilde kısaltıldı. Word'de açmak için:

1. Dosyayı Word ile açın veya içeriği kopyalayın.
2. Yazı tipi: 11 pt, kenar boşlukları: normal (2,5 cm).
3. Gerekirse başlık satırını kurum şablonuna uyarlayın.
